# 계획 상세 페이지와 기간 목표 설계

작성: 2026-10-17 (Asia/Seoul)
상태: 2026-10-17 사용자 승인. V2 구현 대상. 새 카드는 주간·월간 탭 모두 표시한다.

## 의도와 범위

일일 계획 시간표에서 상위 카드에 설정한 세부목표를 바로 확인하고 편집할 수 있게 한다. 월간·주간 목표를 일간 분량으로 배분하고, 공부 도중 추가되는 관련 카드도 사용자가 확인한 뒤 배분할 수 있게 한다. 시간표와 목록은 동일한 계획을 보여주며, 계획을 여러 화면에서 따로 관리하게 만들지 않는다.

사용자가 정한 방향:

- 일일 계획 탭 오른쪽에 펼치기 버튼을 추가한다.
- 펼치면 계획 상세 보기·편집 페이지를 연다.
- 기본 화면에는 일간 계획 목록과 각 계획의 세부목표를 표시한다.
- 주간·월간 계획도 같은 페이지에서 조작할 수 있다.
- 기간 목표를 세운 뒤 그 하위 또는 같은 과목·단원에 카드가 추가되면 월간 탭에서 보여주고, 그 자리에서 배분한다.
- 시간 블록 복사도 함께 다룬다.

이 문서의 기본 제안은 날짜별 분량까지 자동 배분하는 것이다. 카드별 예상 소요시간을 추가로 입력하게 하거나 시작·종료 시각을 자동 추정하지 않는다. 아래의 세부 규칙은 이 제안을 검토하기 위한 구체적인 기본값이다.

## 1. 진입과 화면 구성

일일 계획 패널 오른쪽 위에 `계획 상세 펼치기` 버튼을 둔다. 데스크톱에서는 왼쪽 시간표 옆에 상세 패널을 열고, 두 영역의 합계 너비는 화면 절반 이하로 제한한다. 오른쪽 학습 페이지는 계속 표시하며 카드 편집·이동·끌어놓기가 가능해야 한다. 시간표와 하단 메뉴가 기존처럼 화면 높이 안에 들어와야 한다.

상세 페이지에는 `일간 / 주간 / 월간` 탭을 둔다. 처음 열면 시간표에서 선택한 날짜의 일간 탭을 보여준다. 날짜를 어느 쪽에서 바꾸든 시간표와 일간 목록이 함께 바뀐다. 일일 계획의 날짜는 숫자 직접 입력 또는 브라우저 날짜 선택기를 사용하며 별도 안내 툴팁·모달을 열지 않는다. 펼치기·탭 전환·접기는 학습 페이지의 경로를 바꾸지 않으며, 상세 패널에서 원본 카드를 열어도 패널을 유지한다.

좁은 화면에서도 계획 영역은 화면 절반 이하를 유지한다. 왼쪽에는 시간표 또는 상세 패널을 하나씩 표시하며 `시간표` 버튼으로 전환한다. 오른쪽 학습 카드의 도구는 줄바꿈하여 조작할 수 있게 한다.

주간·월간 탭은 날짜 선택 줄 → 기간 목표 → 달력 → 새 카드 순서로 보여준다. 기간 목표 영역에 학습 카드 본문을 끌어놓으면 보고 있는 주(월요일~일요일) 또는 달 전체를 기간으로 목표를 만든다. 미완료 하위 학습 항목과 모든 요일을 기본으로 선택하며, 편집에서 바꿀 수 있다. 같은 카드·목표 종류·기간의 반복 드롭은 기존 목표를 유지한다. 기존 일간 계획을 이 영역으로 끌어놓아도 원래 계획의 배치와 실행 기록은 유지하고 기간 목표만 만든다. 일간 배정은 기존 배분 미리보기와 확정을 거친다.

주간 달력은 월요일부터 일요일까지 날짜별 다이어리 칸, 월간은 월요일 시작 7열 달력으로 이전·다음 달의 이어지는 날짜까지 표시한다. 카드 본문을 날짜 칸에 끌어놓으면 시간 미지정 일간 계획을 만들고, 달력의 계획 카드를 다른 날짜로 끌면 동일한 계획을 이동한다. 계획의 시간·길이·세부목표는 보존하되 실제 공부 기록은 실행 날짜에 남긴다. 달력 카드에서 시간표로 끌어놓아 10분 단위 시각을 지정할 수도 있다. 월간 칸은 카드 2개와 나머지 개수 버튼을 보여주며, 날짜 또는 개수 버튼은 전체 일간 목록을 연다.

```mermaid
flowchart LR
  S[일일 계획 시간표] -->|펼치기| D[계획 상세 · 일간 목록]
  D --- W[주간 보기]
  W --- M[월간 보기]
  M --> N[새 카드 확인]
  N --> A[날짜별 배분 미리보기]
  A --> D
  D -->|날짜·시간·세부목표 편집| S
```

## 2. 일간 목록

선택 날짜의 계획을 시작 시각 순서로 나열하고, 시간 미지정 계획은 별도 묶음으로 표시한다. 계획을 찾기 위해 우클릭 메뉴를 열지 않아도 선택된 세부목표가 기본적으로 보인다.

예시:

    19:00–20:00  경영학                       1 / 3
      ✓ 동기부여 이론 · 핵심이론
      □ 동기부여 이론 · 기타이론
      □ 동기부여 이론 · 기타이론 · 기출문제

- 각 행에 과목/단원명, 예정 시각 또는 시간 미지정, 진행률, 세부목표를 표시한다.
- 세부목표를 지정하지 않은 계획은 상위 카드 자체를 진행률 기준으로 사용하는 현재 동작을 유지한다.
- 행에서 세부목표 편집, 날짜 이동, 시간 변경, 계획에서 제거를 할 수 있다. 시간 변경은 현재와 동일하게 10분 단위, 00:00–다음 날 02:00 범위다.
- 세부목표 체크박스는 연결된 원본 카드의 완료 상태를 바꾼다. 복제된 별도 완료 상태를 만들지 않는다.
- 제목은 해당 학습 페이지를 연다. 목록의 기록 시작/정지는 별도 버튼으로 제공한다. 시간표 카드 클릭의 기존 기록 시작/정지 동작은 유지한다.
- 날짜를 옮겨도 실행 기록은 실제 공부한 날짜에 남는다.
- 목록에서 편집하면 시간표, 진행률, 남은 할 일도 즉시 갱신한다.

## 3. 월간·주간 목표

월간 목표와 주간 목표는 같은 '기간 목표' 데이터를 사용한다. 차이는 기본 날짜 범위다. 월간은 선택한 달, 주간은 선택한 주의 월요일부터 일요일까지를 기본으로 한다. 사용자가 기간을 조정할 수 있다.

목표를 만들 때 과목/단원, 기간, 공부할 요일, 배분할 하위 카드를 정한다. 기존 카드 선택 UI와 계층 정보를 재사용한다. 한 항목에서 상위 묶음 전체와 그 하위 카드를 중복 배분하지 않도록 한다.

기본 배분 목록은 미완료 학습 단위다. 이론 탭과 문제는 각각 학습 단위이고, 하위 학습 항목이 없는 주제는 그 자체가 한 단위다. 상위 과목·단원은 화면에서 이 항목들을 묶는 이름으로 사용한다. 사용자는 배분 전에 필요한 항목만 선택할 수 있다.

주간 탭에는 해당 주의 날짜별 배정과 겹치는 기간 목표를 보여준다. 월간 목표를 배분했다고 별도의 주간 목표를 자동 복제하지 않는다. 월간 탭에는 그 달과 겹치는 월간·주간 목표 및 새 카드 목록을 함께 보여준다.

목표의 배정 분량은 고유한 학습 항목을 기준으로 계산한다. 이미 같은 목표에서 배분한 항목은 다시 자동 배분하지 않는다. 서로 다른 목표의 범위가 겹치면 기존 배정 위치를 보여주고, 기본 배분에서는 이미 배정된 항목을 제외한다. 사용자가 명시적으로 만드는 복습 계획은 별도 계획으로 유지한다.

세부목표를 지정하지 않은 상위 과목·단원 계획은 상위 카드 자체만 배정한 것으로 본다. 그 하위 이론·문제까지 모두 배정했다고 간주하여 기간 목표의 배분을 막지 않는다. 명시적으로 선택한 세부목표는 기존 배정으로 계산하며, 선택한 단원 묶음은 그 안의 학습 항목도 포함한다.

## 4. 날짜별 배분

`배분`을 누르면 선택 항목을 대상 날짜에 나눈 미리보기를 먼저 보여준다. 기본 대상 날짜는 목표 기간 안에서 오늘 이후의 선택 요일이다. 지난 날짜에는 자동으로 넣지 않는다.

- 카드의 현재 순서를 유지하면서 개수가 가능한 한 균등하도록 배분한다. 이는 학습시간이 균등하다는 뜻은 아니다.
- 확정 시 각 날짜에 해당 과목/단원 계획과 세부목표를 만든다. 초기 상태는 시간 미지정이다.
- 같은 기간 목표의 계획이 그 날짜에 이미 있으면 세부목표를 추가한다. 날짜와 시간 범위는 유지한다.
- 시간표에 배치할 때 시작·종료 시각을 정한다. 상세 목록에서도 시간을 지정할 수 있다.
- 사용자가 직접 배치한 다른 계획이나 완료된 과거 계획을 자동으로 이동하지 않는다.
- 대상 날짜가 없으면 자동 배분을 실행하지 않고 기간 또는 날짜를 수정할 수 있게 한다.
- 확인 버튼을 반복해서 눌러도 같은 배분을 중복 생성하지 않는다. 미리보기 이후 원본 카드나 계획이 바뀌었으면 최신 상태로 다시 계산해 보여준다.

## 5. 새 카드 발견과 주간·월간 탭

목표에는 '새 카드를 확인할 범위'를 둔다. 기본은 목표로 선택한 과목/단원이다. 더 작은 카드를 골랐으면 그 카드가 속한 단원을 기본 범위로 삼고, 목표 생성 시 범위를 이름으로 표시하여 사용자가 알 수 있게 한다. 따라서 같은 단원 안에서 옆에 새 이론이나 문제가 추가돼도 찾을 수 있다.

목표를 만들 당시 그 범위에 있던 카드들을 기억한다. 현재 범위의 카드와 비교하여 나중에 추가되거나 새로 들어온 카드만 주간·월간 탭 모두의 `새 카드` 목록에 표시한다. 두 탭은 같은 목록과 배분 동작을 사용하며, 현재 주/달에 걸친 목표를 대상으로 한다. 기존 카드의 이름이나 본문만 수정한 것은 새 카드로 취급하지 않는다.

새 카드 행에는 과목/단원 경로, 관련 목표, 완료 상태, 기존 배정 여부를 보여준다. 같은 카드가 여러 목표에 걸려도 목록에서는 한 번만 보여주며 관련 목표들을 함께 표시한다.

사용자는 새 카드들을 선택하여:

- 관련 목표에 포함하고 원하는 날짜 또는 남은 날짜들에 배분한다.
- 해당 목표에서 제외한다. 제외한 카드를 다시 매번 새 카드로 띄우지 않는다.

선택하여 포함하기 전에는 새 카드 때문에 기존 기간 목표의 배정 목록이나 목표 개수가 늘어나지 않는다. 지난 계획의 날짜·시간·선택된 세부목표와 실행 기록을 자동으로 다시 쓰지 않는다. 새 카드 목록을 위해 카드 복사본을 만들지 않는다.

카드가 삭제되거나 범위 밖으로 이동하면 배분 가능한 새 카드 목록에서 빠진다. 원본 카드 이동 시 기존 참조를 갱신하는 경로에도 기간 목표 참조를 포함한다. 종료된 목표의 새 항목은 자동으로 과거에 배분하지 않으며, 목표 기간을 조정하거나 다른 목표를 선택할 수 있게 한다.

이 기능은 기존의 원본 카드 완료 상태를 사용하는 일간 진행률 정책을 바꾸지 않는다. 과거의 모든 진행률을 별도 기록으로 고정하는 기능은 이번 변경에 포함하지 않는다.

## 6. 시간 블록과 계획 복사

일간 상세 페이지에 `다른 날짜로 복사`를 제공한다. 원본은 선택 날짜이며, 대상 날짜는 여러 개 선택할 수 있다.

| 선택 | 복사할 내용 |
| --- | --- |
| 시간 블록만 — 기본값 | 블록의 시각, 이름, 색상 |
| 계획 카드도 포함 | 위 내용과 계획 카드의 위치, 시간 길이, 선택된 세부목표 |

실행 세션, 누적 실행시간, 실행 중 상태는 복사하지 않는다. 원본 학습 카드의 완료 상태도 바꾸지 않는다. 당일 전용 할 일은 새 항목으로 복사하며 완료·실행 상태를 초기화한다. 기간 목표의 배분 연결은 자동 복제하지 않아 복사만으로 같은 목표 분량이 중복 집계되지 않게 한다.

복사 전 미리보기에서 대상 날짜의 기존 블록/계획과 겹치는 내용을 보여준다. 기본 동작은 추가이며 기존 데이터를 덮어쓰거나 삭제하지 않는다. 동일 복사 작업의 중복 적용을 막고 원본 날짜는 대상으로 선택하지 못하게 한다.

## 7. 기존 코드와 연결

구현은 우선 `cpa_app_timetable_monthly_v2.html`에서 진행한다. 검증 후 메인 반영은 별도로 한다.

- `#/plans/day`, `#/plans/week`, `#/plans/month` 경로를 기존 라우터에 추가한다.
- 기존 `dailyHistory`와 계획 참조를 상세 목록과 시간표가 함께 사용한다.
- `timelineSubgoalOptions`, `selectedTimelineSubgoals`, `getCardInfo`와 기존 원본 완료·기록·탐색 동작을 재사용한다.
- 기간 목표는 별도 목록으로 저장하며 식별자, 범위 카드, 날짜/요일, 선택된 학습 항목, 확인한 카드 목록을 가진다.
- 배분된 일간 계획에는 기간 목표 식별자를 연결한다. 원본 카드 참조와 일간 계획 자체의 식별자는 구분해 이동·복사·중복 처리를 안정적으로 한다.
- 기존 계획에는 안정적인 계획 식별자만 보완하고 날짜·시각·세부목표·실행 기록은 보존한다. 기간 목표가 없는 기존 계획도 그대로 편집할 수 있어야 한다.
- 기간 목표 삭제는 원본 학습 카드를 삭제하지 않는다. 이미 배분한 일간 계획은 남겨 독립 계획으로 전환한다.
- 스키마 변경, 정규화, 가져오기 검증, 원본 참조 변경/삭제, 공식 JSON 백업 복원을 함께 갱신한다. 구버전 데이터에 기간 목표가 없으면 빈 목록으로 변환한다.
- 메인/V2 저장 공간 분리와 공유 이미지 보존 정책을 유지한다.
- README 및 DATA_FORMAT에 실제 구현한 사용법과 데이터 규칙을 반영한다.

## 8. 검증 기준

1. 펼치기·접기, 날짜 이동, 학습 페이지 복귀에서 선택 날짜와 시간표 상태가 유지된다. 모바일에서도 상세 페이지와 시간표를 오갈 수 있다.
2. 상위 카드의 선택된 세부목표가 기본으로 보이고, 체크·편집 결과가 시간표와 목록에 동일하게 반영된다.
3. 주간·월간 목표의 배분이 시간 미지정 일간 계획에 나타나고, 날짜·요일·중복 제외 규칙을 지킨다.
4. 목표 생성 후 하위/같은 단원에 추가한 카드만 새 항목으로 표시된다. 이름 수정, 삭제, 이동, 여러 목표의 범위 중복도 처리한다.
5. 새 항목 포함·제외 및 재배분이 기존 시각·실행 기록을 건드리지 않고, 반복 실행으로 중복 계획을 만들지 않는다.
6. 복사 시 원본·대상 기록이 보존되고, 실행시간과 실행 중 상태가 복제되지 않는다. 자정 이후 계획도 기존 26시간 범위 안에서 유지된다.
7. 기존 데이터 마이그레이션, 공식 백업 왕복, 원본 카드 이동/삭제 후 참조, 메인/V2 분리가 유지된다.
8. 기존 시간표 회귀 테스트와 새 계획 데이터/배분 테스트가 통과한다. 실제 브라우저에서 세부목표 표시·편집, 새 카드 배분, 복사를 확인한다.

## 검토할 핵심 기본값

새 항목은 자동 감지만 하고 사용자가 월간 탭에서 포함·배분한다. 자동 배분은 날짜별 분량까지이며, 시각은 시간표 또는 상세 목록에서 지정한다. 이 두 기본값을 포함하여 본 문서를 검토한 뒤 구현 계획으로 넘어간다.
